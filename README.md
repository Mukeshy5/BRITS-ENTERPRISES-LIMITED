# BRITS ENTERPRISES LIMITED

A premium corporate web application for **BRITS ENTERPRISES LIMITED**, a UK-registered global business specializing in multi-sector solutions including Aviation, Logistics, Lifestyle products, and Interior finishes.

## Key Features

- **Dynamic Product Catalog**: Automatically scans the `assets` folder and analyzes filenames to generate meaningful product titles and descriptions.
- **Aviation & Logistics Hub**: Dedicated service sections for Ground Handling, Cargo Charters, and Secure Warehousing.
- **Premium Branding**: Custom typography (Montserrat & Open Sans) and a "Navy & Gold" luxury aesthetic.
- **Responsive Design**: Fully optimized for all device types (Mobile, Tablet, Desktop).
- **Global Reach**: Professional "Contact" and "Enquire" portals for international client engagement.

## Tech Stack

- **Frontend**: React.js with Vite
- **Styling**: Tailwind CSS
- **Navigation**: React Router DOM
- **Icons**: FontAwesome & Custom Emojis

## Setup Instructions

1. **Install Dependencies**:
   ```bash
   npm install
   ```
2. **Run Development Server**:
   ```bash
   npm run dev
   ```
3. **Build for Production**:
   ```bash
   npm run build
   ```
